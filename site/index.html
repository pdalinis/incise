Intent in. Exact edit out.

incise table-update-cell vault/Projects.md \
  --table Projects \
  --where Note=Launch \
  --column Status \
  --value done

The row is selected by content. Incise adjusts table padding when needed and leaves the rest of the file alone.

Semantic addresses

Target headings, cell values, item text, keys, and ordinals instead of stale line numbers.

Byte-preserving

Change the smallest structural range possible. Unrelated prose, formatting, and line endings survive.

One install. The right profile for the model.

Ornith + Pi

pi install npm:pi-incise
INCISE_PROFILE=auto pi --thinking off

Configure maxTokens: 2048 and parallel_tool_calls: false. Auto-detection enables the 480/480 measured profile.

Gemma + Pi

pi install npm:pi-incise
INCISE_PROFILE=auto pi

Auto-detection enables the measured guarded routes for Gemma and keeps the standard tools as fallback.

MiniCPM + Pi

pi install npm:pi-incise
INCISE_PROFILE=standard pi

Use the model-agnostic standard profile generally. A narrow opt-in list pipeline is available for evaluation.

Gemma or Ornith + Hermes

cargo install incise-cli --locked
INCISE_PROFILE=auto hermes chat

Measured automatic routing reached 480/480 on both models while retaining Hermes file safety and standard-tool fallback.

Measured, not merely claimed

Hermes auto achieved 480/480 on both Ornith and Gemma: perfect tables, lists, sections, frontmatter, and table reads, with 360/360 exact routed calls in each run. Ornith improved from 460/480 on standard Hermes to 480/480 with 20 paired wins and no regressions. Pi remains 480/480 on Ornith and 475/479 usable on Gemma, both with zero harmful outcomes.

MiniCPM support is intentionally narrower: singleton table-row compatibility passed 18/18 live trials, and a host-routed list pipeline reached 21/21 in its direct arm. The real Pi list profile reached 16/21 with every executed edit correct, so it remains opt-in.
