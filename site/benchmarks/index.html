Why the Gemma profile works

Inspect before editing

Pi reads the current table, list, outline, or flattened frontmatter structure and retains its content hash.

Route only exact intent

Unambiguous requests receive one small action-specific tool. Unsupported wording keeps the standard interface.

Own dangerous arguments

The host supplies resolved targets, exact predicates, typed values, and create/update preconditions, then stops after one successful routed mutation.

What the operations remove

Character arithmetic

The model no longer needs to count table padding or reproduce formatting exactly.

Boundary guesses

Section and list boundaries are determined by deterministic structure-aware code.

Whole-document rewrites

Targeted splices avoid recreating unrelated bytes and consuming them as model output.

Reproducible evidence

The complete tasks, prompts, raw calls, graders, preregistered plans, statistical comparisons, caveats, failed treatments, and reversed conclusions are versioned with the source.
