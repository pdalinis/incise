Knowledge bases

Let agents change a fact without rewriting a note.

Markdown vaults accumulate wikilinks, block IDs, callouts, embeds, task lists, comments, and personal formatting. Incise targets the structure an agent intends to change and leaves everything else untouched.

Where Incise fits

Incise is not a knowledge graph, semantic-search engine, or vault index. Use your preferred agent or retrieval system to decide which file and fact need attention; use Incise as the deterministic mutation layer after that decision.

A safer maintenance loop

  1. The agent locates the relevant Markdown file.
  2. Incise exposes only its table, list, heading, or frontmatter structure.
  3. The agent selects a target by content.
  4. Incise performs a minimal edit or returns an actionable refusal.

Good fits

Project dashboards

Update status tables and task lists without reformatting the page.

Daily notes

Toggle tasks or append to a known section while retaining the surrounding journal.

Metadata workflows

Change nested frontmatter used by publishing, indexing, or automation.
