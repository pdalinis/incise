Documentation

Install once. Edit Markdown safely.

Use Incise from the command line, install the native Pi package, or connect the version-matched Hermes plugin. Ornith and Gemma get measured automatic profiles; other models keep the stable standard interface.

Command-line installation

cargo install incise-cli --locked
incise --version

Linux and macOS archives are also available from GitHub Releases.

Pi installation

pi install npm:pi-incise

The npm package includes native binaries for macOS arm64/x64 and glibc Linux arm64/x64.

Ornith 1.5 9B

INCISE_PROFILE=auto pi --thinking off

Recommended with maxTokens: 2048 and samplingParams.parallel_tool_calls: false. Run /incise-doctor after startup.

Gemma

INCISE_PROFILE=auto pi

Recommended. Auto-detection enables the measured guarded routing profile. Run /incise-doctor after startup.

MiniCPM

INCISE_PROFILE=standard pi

Recommended for general work. Use minicpm-list only to evaluate the narrow measured list pipeline.

Other models

INCISE_PROFILE=standard pi

The model-agnostic eight-tool interface remains the compatibility default.

Hermes Agent installation

Install the CLI first, then download the plugin bundle from the same release:

release="v$(incise --version | awk '{print $2}')"
mkdir -p "$HOME/.hermes/plugins"
curl --fail --location --silent --show-error \
  "https://github.com/pdalinis/incise/releases/download/$release/incise-hermes-$release.tar.gz" \
  | tar -xz -C "$HOME/.hermes/plugins"

hermes plugins enable --no-allow-tool-override incise
hermes tools enable --platform cli incise
hermes plugins doctor --ci incise

Keep the CLI and plugin on the same release. Doctor prints the exact Incise binary it validated and reports eight handlers for standard or twenty-four for auto; request middleware narrows the latter to exactly one routed Incise tool or the standard eight before inference.

Gemma

INCISE_PROFILE=auto hermes chat

Recommended. If the provider uses a generic model alias, add INCISE_MODEL_FAMILY=gemma.

Ornith 1.5 9B

INCISE_PROFILE=auto hermes chat --reasoning none

Also configure a 2,048-token output cap and disable parallel tool calls. For a generic alias, add INCISE_MODEL_FAMILY=ornith.

Other models

INCISE_PROFILE=standard hermes chat

Unknown models and MiniCPM retain the stable model-agnostic interface under auto as well.

The preregistered Hermes profile completed 480/480 trials on both Ornith and Gemma with zero harmful outcomes.

The editing loop

  1. Inspect the relevant document structure.
  2. Address the target by its content.
  3. Preview or perform one semantic operation.
  4. Verify the concise result or follow the remedy in a refusal.
incise tables vault/Projects.md
incise rows vault/Projects.md --table Projects
incise table-update-cell vault/Projects.md \
  --table Projects --where Note=Launch \
  --column Status --value done

Supported structures

StructureOperations
TablesAdd and delete rows, update cells, query rows, realign columns
ListsAdd and remove items, toggle task checkboxes
SectionsAppend, replace, insert, delete, rename, change heading level
FrontmatterRead, set, and delete nested YAML keys

Agent integrations

Print the standard function schemas with incise schema or inspect the experimental narrow surface with incise schema --profile safe-small. See the complete guides for Hermes Agent and Pi.

Need every command and option? Run incise --help or incise <command> --help. The project README covers safety, compatibility, and development.
